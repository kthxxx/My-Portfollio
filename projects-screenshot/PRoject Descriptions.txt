 Bible Voyagers: Adventures Through Scripture                                                                                                                                 
                                                                                                                                                                                   
  ### 🌟 Project Tagline                                                                                                                                                           
                                                                                                                                                                                   
  │ A peaceful, offline-first 2D educational platformer and reading journal designed to help children (ages 8–10) explore Biblical stories through interactive gameplay, scripture 
  │ comprehension, and exploration.                                                                                                                                                
  ──────                                                                                                                                                                           
  ### 📝 Short Summary (Ideal for Portfolio Cards / LinkedIn)                                                                                                                      
                                                                                                                                                                                   
  Bible Voyagers is a full-stack educational web application and 2D platformer built with React 19, TypeScript, and Phaser. It pairs gamified exploration with scripture reading   
  and comprehension quizzes across interactive story worlds (e.g., Noah’s Ark, Joseph in Egypt, Moses and the Exodus, David the Shepherd). Built with an offline-first architecture
  using Dexie.js (IndexedDB) and backed by Supabase Auth, the app enforces child safety and privacy by strictly separating caregiver credentials from the child’s in-game profile. 
  ──────                                                                                                                                                                           
  ### 🛠️ Key Technical Highlights (What Recruiters Look For)                                                                                                                       
                                                                                                                                                                                   
  • Hybrid React + Phaser Engine: Seamlessly embedded a Phaser 2D game engine within a modern React 19 single-page application, handling physics, custom tilemap scenery, player   
  movement, climbing mechanics, collectibles, and mobile touch controls.                                                                                                           
  • Offline-First & Resilient Storage: Designed an IndexedDB persistence layer using Dexie.js to track player journeys, collectibles, quest progress, and badges locally, allowing 
  smooth gameplay with zero latency and offline support via PWA.                                                                                                                   
  • Child Privacy & Caregiver Guardrails: Implemented a family authentication gate using Supabase Auth (email/password & Google OAuth) to keep parent credentials and session      
  recovery isolated from child player personas (no ads, no microtransactions, zero tracking).                                                                                      
  • Interactive Learning & Guarded Progress: Built an interactive reading journal coupled with a retryable 5-question comprehension quiz system, guarded route validation, and     
  persistent digital badge awards in a custom Discovery Room.                                                                                                                      
  • Rigorous Testing & Accessibility: Implemented automated end-to-end integration tests using Playwright and Vitest, adhering to strict accessibility standards verified with Axe-
  core (mobile viewport audits down to 320px/390px, keyboard navigation, and high-contrast compliance).
