# Portfolio photos

Add your original and generated portfolio photos to this folder.

Recommended filenames:

- `keith-hero.webp` — fullscreen landing image
- `keith-portrait.webp` — portrait or About section image
- `project-resilinav.webp` — ResiliNav preview
- `project-sentinel.webp` — SentinelAI preview
- `creative-design.webp` — graphic design work
- `creative-photography.webp` — photography work
- `creative-video.webp` — video or media work

Use lowercase filenames with hyphens and no spaces. Prefer WebP or AVIF, and keep each image below approximately 500 KB when possible.

Images in this directory are available from the site as `/photos/filename.webp`.
